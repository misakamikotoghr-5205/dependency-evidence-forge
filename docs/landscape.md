## Borrowing and licensing

Only product/algorithm design was studied. No source, tests, screenshots or assets were copied from the comparison repositories, and neither was installed as a dependency. The graph algorithms are independently written. No claim is made that this combination is unique.

Actual reused dependencies are the official Forge SDKs and React, with pinned npm versions and a lockfile. The Forge SDK license files refer to Atlassian Developer Terms; they are **not relabeled MIT**. See [third-party notices](../THIRD_PARTY_NOTICES.md). Our original implementation and fictional fixtures are MIT.

## Substantive implementation and verification

The improvement is a complete local capture → freeze → current capture → recheck/report workflow. It preserves the chosen site/root/type/direction, source, updated instants, link IDs, permission/collection failures and a checksum. It explains blocker paths and SCC groups. Timestamp-only edits, newly reachable records and disappeared dependencies invalidate the old review. Missing data cannot silently become completed work.

Nineteen tests exercise pagination, stalled tokens, depth/page/node bounds, unknown fields and status, permission failures, root/site binding, scope mismatch, digest editing, reopened dependencies, cycles, changed timestamps, immutable old output and HTML escaping. `npm run check` also type-checks against actual UI Kit types, compiles UI/backend locally and invokes the actual SDK resolver without a live context to verify rejection before network access. It generates a runnable fictional report; no real Jira or deployed Forge result is claimed.

Implementation followed the official [issue panel](https://developer.atlassian.com/platform/forge/manifest-reference/modules/jira-issue-panel/), [resolver/makeResolver](https://developer.atlassian.com/platform/forge/runtime-reference/forge-resolver/), [asUser/route](https://developer.atlassian.com/platform/forge/apis-reference/fetch-api-product.requestjira/), [enhanced JQL search](https://developer.atlassian.com/cloud/jira/platform/rest/v3/api-group-issue-search/#api-rest-api-3-search-jql-post) and [app-context security](https://developer.atlassian.com/platform/forge/app-context-security/) documentation. These are API contracts; authenticated installation and current-site behavior still require real testing.
